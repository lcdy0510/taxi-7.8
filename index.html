수평·수직 이동에 기울기가 m 또는 −m인 대각선 이동을 추가하면, 거리 1 이하인 점들의 모양은 어떻게 변할까요?

그래프 해석

파란색 도형은 새롭게 정의한 거리에서 원점으로부터의 거리가 1 이하인 점들의 집합입니다. m이 0이 아니면 일반적으로 중심대칭인 팔각형이 나타나며, |m| = 1일 때 정팔각형이 됩니다. m = 0이면 대각선 이동 방향이 수평 방향과 겹치므로 기존 택시 기하의 마름모가 나타납니다.

이 모델은 수평·수직 방향과 기울기가 m 또는 −m인 방향으로만 이동할 수 있고, 각 선분의 길이는 유클리드 길이로 계산한다고 가정합니다. 따라서 m과 −m의 허용 방향 집합은 동일하며, 도형은 m의 부호가 아니라 |m|에 따라 결정됩니다.

t = |m|, a = |x₂ − x₁|, b = |y₂ − y₁|
t = 0이면 d = a + b
t > 0이고 b ≤ ta이면 d = a + ((√(1+t²) − 1)/t)b
t > 0이고 b ≥ ta이면 d = b + (√(1+t²) − t)a
